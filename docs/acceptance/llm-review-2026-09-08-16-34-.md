## 发现的问题

### 严重级别：中等
1. **回链更新逻辑存在数据一致性风险**  
   `src/main/db/inspirations.ts` 的 `updateInspiration` 函数中，回链更新逻辑复杂且不安全。当仅传入 `refId` 而不传 `refType` 时，会单独更新 `refId`，导致回链不完整（缺少 `refType`）。建议解绑操作必须同时传入 `refType=''` 和 `refId=''`，或强制成对更新。

2. **清空回收站功能缺失**  
   验收点要求“清空回收站（确认弹窗）”，但DAO层无批量删除API，前端亦未提供实现代码。若通过循环调用 `removeInspiration` 实现，效率低且非原子操作，用户确认后可能产生部分删除的中间状态。

### 严重级别：低
3. **关联词条校验性能隐患**  
   `createInspiration` 和 `updateInspiration` 中，对 `wikiRefs` 数组中的每个词条ID逐个发起数据库查询。若关联词条较多，将产生大量IO，建议改为 `WHERE id IN (...)` 批量查询。

4. **IPC层校验不完整**  
   `src/main/ipc/inspirations.ts` 中，`update` 通道校验了 `refId` 的UUID格式，但未校验 `refType`。虽然DAO层有白名单校验，但IPC层应提前拦截非法输入，符合防御性编程原则。

5. **浮球拖拽状态未清理**  
   `src/renderer/src/components/AssistantDock.vue` 中，`ballDragStart` 和 `suppressBallClick` 为模块级变量，若组件卸载时未清理，可能导致残留状态。建议在 `onUnmounted` 钩子中重置。

## 无法判定项

1. **词条删除后卡片降级显示**：前端渲染时如何判断词条已删除并显示“已删词条”，需查看 `InspirationsWallView.vue` 完整代码。
2. **情节节点创建位置计算**：验收点要求“落位 maxX+340”，但diff中未体现位置计算逻辑，需查看 `SendToCanvasDialog.vue` 和 `PlotCanvasView.vue` 相关代码。
3. **PlotDetailPanel来源行渲染**：如何根据 `refId` 查询便签并渲染来源行，需查看 `PlotDetailPanel.vue` 完整代码。
4. **划词选区获取稳定性**：自测使用 `Range` 定位+键盘扩选，但实际用户操作中选区获取是否稳定，需实际运行测试。
5. **同路由跨书导航bug修复**：自测声明已修复 `2a22898`，但需查看 `InspirationsWallView.vue` 的 `computed+watch` 实现确认。
