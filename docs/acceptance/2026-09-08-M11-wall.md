### 2. 编辑便签内容保存生效 — PASS

### 4. 彻底删除 / 清空回收站 — PASS

### 5. 入画布 → 情节大纲事件 — PASS

- 卡片出现「已入画布」角标（卡片文本：`片段 | 已入画布 | 城头对峙 | … | 查看 | 解绑`）。

### 6. 已入画布按钮变化 / 查看跳转 / 解绑 / 重入画布 — PASS
