## 发现的问题  

### 1. 严重：`saveGenesisStep` 写入 `data` 为 `undefined` 导致数据库约束冲突  
- **文件** `src/main/db/genesis.ts`  
- **代码** `data: JSON.stringify(input.data)`  
- **问题** 当 `input.data` 为 `undefined` 时，`JSON.stringify(undefined)` 返回 `undefined`（而非字符串），传递给 prepared statement 后可能被 SQLite 视为 `NULL`，违反 `data TEXT NOT NULL` 约束，导致写入失败。  
- **严重级别** 🔴 高  
- **建议** 改为 `data: JSON.stringify(input.data ?? {})`。

### 2. 严重：`aiWriting.ts` 中访问 `s.cheat` 未做空值保护，可能运行时崩溃  
- **文件** `src/renderer/src/services/aiWriting.ts`（diff 截断处可见访问 `s.cheat.coreAbility`）  
- **问题** `ctx.genesis.soul` 可能来自数据库旧数据，`cheat` 字段可能缺失，直接访问 `s.cheat.coreAbility` 会抛出 `TypeError`，导致 AI 续写完全失败。  
- **严重级别** 🔴 高  
- **建议** 使用可选链 `s.cheat?.coreAbility` 或提前校验。

### 3. 严重：创世台缓存竞态与残留污染  
- **文件** `src/renderer/src/components/ChapterEditor.vue`  
  - `loadGenesis` 成功时直接设置 `genesisCache.value`，若切换书籍后旧请求延迟返回，会覆盖新书设定。  
  - 加载失败时不清空 `genesisCache`，导致使用上一本书的设定注入当前书写作。  
- **严重级别** 🔴 高  
- **建议** 使用请求序列号或 `AbortController`，并在加载前清空缓存，失败时重置为默认值。

### 4. 中等：写作规则 `targetWords` 为 `0` 时被错误丢弃  
- **文件** `src/renderer/src/components/ChapterEditor.vue`  
  `const rules = layout?.rules?.targetWords || layout?.rules?.forbidden || layout?.rules?.styleNotes ? layout.rules : undefined`  
  `targetWords` 为 `0` 时 falsy，即使 `forbidden` 或 `styleNotes` 有值也会被忽略，导致写作规则丢失。  
- **严重级别** 🟡 中  
- **建议** 改用显式判断 `layout?.rules && (layout.rules.targetWords !== undefined || layout.rules.forbidden || layout.rules.styleNotes) ? layout.rules : undefined`。

### 5. 中等：`ChapterSidebar` 可能缺少 `bookId` 传递  
- `ChapterSidebar.vue` 新增 `bookId` prop，但未在父组件 `WorkspaceView.vue` 的 diff 中看到传入该 prop 的修改，可能导致链接为 `/book/undefined/genesis`。  
- **严重级别** 🟡 中（若确实未传则高）  

### 6. 低：`saveGenesisStep` 返回值使用非空断言 `!`，异常时可能抛出未捕获错误  
- **文件** `src/main/db/genesis.ts`  
  `return getGenesisStep(bookId, input.step)!` 在查询失败时返回 `undefined`，`!` 断言会导致运行时错误。  
- **严重级别** 🟢 低（概率极低）  

## 无法判定项（需运行验证）  
- 所有涉及前端交互的验收点（1~6）因缺少 `GenesisView.vue` 代码均无法判定。

- 持久化重启不丢、流式生成 JSON 填表、冷启动四段生成等行为需在 Electron 环境运行验证。

**建议** 补充完整的 `GenesisView.vue` 及配套组件代码，修复上述严重缺陷后重新提交验收。
