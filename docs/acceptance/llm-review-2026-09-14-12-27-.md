## 发现的问题

1. **[严重] 启动画面移除逻辑缺失/矛盾**  
   材料强调修复了 rAF 冻结导致 splash 永久残留的必现 bug（b9df80d），并改用 `setTimeout`。但在 `App.vue` 的 diff 中，`onMounted` 仅有 `void initTheme()` 和 `startAutoSync()`，**无任何针对 `#boot-splash` 的 DOM 移除或淡出逻辑**。若代码确实遗漏，将导致 splash 永久遮挡 UI 的严重回归。

2. **[中等] `outline-none` 破坏全局焦点环可访问性**  
   `ApiProfileDialog.vue` 等组件的输入框 class 中仍保留 `outline-none`（如 `outline-none focus:border-ink-primary`）。若 Tailwind 生成 `outline: none` 样式，它会覆盖 `theme.css` 中声明的全局 `:focus-visible` 焦点环，导致键盘导航时焦点不可见，违背无障碍验收点。

3. **[中等] 主题初始化时序引发 FOUC（闪白）风险**  
   `index.html` 使用 `@media (prefers-color-scheme: dark)` 兜底深色底，但应用级主题初始化 `void initTheme()` 放在 `App.vue` 的 `onMounted` 中。当系统为浅色但用户设置保留为深色时，首屏将先渲染浅色纸底，随后异步挂载后才切换深色，造成明显的闪白闪烁。正确做法应在 `main.ts` 顶层或 `<script>` 阻塞阶段同步读取设置并挂载 `data-theme`。

4. **[低] 代码规范微瑕**  
   `brand.ts` 文件末尾无换行符（diff 显示 `\ No newline at end of file`），违反 POSIX 文件规范。

## 无法判定项

- **核心架构实现**：`theme.css` 三层令牌重构、`useTheme.ts` 三模式逻辑、`BookCover.vue` 与 `coverArt.ts` 九题材系统，均因 diff 缺失无法静态审查。
- **焦点环与滚动条**：`theme.css` 中 `:focus-visible` 规则及 `--scrollbar-thumb` 样式定义是否存在，是否会受 `outline-none` 阻断。
- **启动画面生命周期**：`#boot-splash` 在真实 Electron 窗口生命周期中是否被有效移除，且无 DOM 残留。
- **字体加载验证**：`@font-face` 声明是否合规，`document.fonts.check` 是否能通过，子集覆盖度是否达标。
- **图标产物**：`build/icon.ico` 是否真为 7 尺寸 PNG 嵌入容器。
- **运行时表现**：深色下 Vue Flow 画布底色未适配的实际观感、typecheck 闸门与 console 零报错。
