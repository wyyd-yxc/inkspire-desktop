## 发现的问题

1. **【一般】同步弹窗仅勾「回溯事件 → 剧情画布」时「开始同步」按钮禁用，第三目标无法单独执行**
   - 位置：`src/renderer/src/components/sync/SyncDialog.vue` 开始同步按钮
   - 实证：黑盒探针——取消 wiki/记忆、仅勾 plot，按钮 `disabled=true`（截图 m106bb-06-sync-dialog-plotonly-disabled.png）。disabled 条件为 `busy || (!syncWiki && !syncMemory)`，**漏算后接入的第三目标 plot**；而 `start()` 与 WorkspaceView 的 plot 分支本身已接线，仅此守卫未同步更新。
   - 影响：工作台同步弹窗内 plot 必须搭配 wiki/记忆勾选才能执行（本次验收点 6 即以 wiki+plot 组合走通全链）；plot-only 需绕行剧情画布页「⇦ 从正文提取」按钮（该路径验证可用）。
   - 修复建议：条件改为 `busy || (!syncWiki && !syncMemory && !syncPlot)`；修复后复测 plot-only 一项即可。

2. **【轻微·环境】dev 实例陈旧导致整改动具在旧代码上失效的误判风险**：本次实测踩中（见「验收环境与方式」）。非应用缺陷，建议在 HANDOVER 踩坑速查 #13 处补一句「验收/自测前先核对 git HEAD 是否晚于 dev 启动时间」。
