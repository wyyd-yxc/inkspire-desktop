## 发现的问题

1. **【阻断】单击边无法打开连线编辑器 —— `onEdgeClick` 参数签名与 Vue Flow 事件不符**
   - 位置：`src/renderer/src/views/CanvasView.vue` L194-199（`function onEdgeClick(_e: unknown, edge: { id: string })`）
   - 原因：@vue-flow/core 的 `edgeClick` emit 为**单参数** payload `{ event, edge }`（同文件 `onNodeClick(payload: { node: Node })` L268 是正确写法）。此处声明为双参数，第二参 `edge` 恒为 `undefined`，`sceneEdges.value.find(x => x.id === edge.id)` 抛 `TypeError: Cannot read properties of undefined (reading 'id')`。
   - 后果：单击边时 Vue Flow 选中态正常，但编辑器 `v-if="selectedEdge"` 永不为真 → **验收点 3 全部、验收点 4 的 UI 路径不可用**；且每次点击边产生未捕获 console 异常（违反「无 console 报错」自测规范）。
   - 暴露原因：开发自测脚本（tmp/edge-verify.mjs）走 IPC 路径，未覆盖「单击边→编辑器」UI 流程。
   - 修复建议：改为 `function onEdgeClick(payload: { edge: { id: string } })`，取 `payload.edge.id`。修复后需重测：编辑器出现、类型切换即时生效、清标签回车保存、删除按钮、渲染跟随。

2. **【轻微】`shared/canvas.types.ts` 中 `UpdateSceneEdgeInput` 接口重复声明两次**（L81-84 与 L86-89，内容完全相同）。TS 接口合并不报错、typecheck 通过，但应删除一处。

3. **【轻微】拖线建边固定为 main 类型**：`onConnect` 不传 type（DAO 默认 main），用户拖线无法直接建 logic/relation 边，必须经编辑器改类型——而编辑器当前被问题 1 堵死，实际形成「拖线只能建主线」的功能缺口。修复问题 1 后闭环。

4. **【轻微】同对场景的多条平行边完全重叠渲染**：A→B 同时存在 main+logic 两条边时无偏移，仅顶层边 label 可见/可点。v1 边界内可接受，建议后续加偏移或合并展示。
