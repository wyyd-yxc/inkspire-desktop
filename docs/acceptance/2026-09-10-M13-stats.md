## 逐项证据

### 1. 快照自动记录 — PASS
- UI 建书：书架「+ 新建书籍」→ 弹窗真实点击书名框 → 键入「黑盒-M13-统计-甲」→「开始创作」（bookId `7f20487a-…`）。
- UI 建章 2 章（见「缺陷 1」：+新章节按钮真实点击不可达，降级 DOM click() 触发同一 handler，已披露）。
- 真实键盘输入（真实鼠标点击聚焦 .ProseMirror + Input.insertText 模拟输入法上屏），等 3.2s（2s 防抖+余量）：
  - 第 1 章 51 字 → `word_count_snapshots` 今日行 `{day:2026-09-11, base_total:51, last_total:51}` = 全书字数合计 51（首报=基线，delta=0）。
  - 第 2 章 37 字 → 同日仍 1 行，`base=51, last=88`，delta=88−51=37 与新增一致。
- **Ctrl+S 时序鉴别补测**（`tmp/m13-bb-p1s.mjs`，书「黑盒-M13-CtrlS」）：基线 last=10 → 真实键入 20 字后 **193ms** 内按 Ctrl+S → 快照 **350ms** 后落盘 last=20（防抖自动保存需 ≥2000ms，故可归因手动保存）；再等 2.6s 无重复写入。状态栏显示「已保存 · Ctrl+S 立即保存」。
- 测试书已删，快照 0 残留。

### 2. AI 采纳同入账（零 AI） — PASS

## 疑似应用缺陷（非验收点阻塞项）

1. **写作台左侧栏头部溢出，「+ 新章节」按钮被完全遮挡、真实鼠标不可点击（中高危）**
   - 现象：写作台左侧栏（`ASIDE.w-60`=240px）顶部一行（←书房 / 构思台…统计 pills / 同步 / +新章节）空间不足，pills 挤压成竖排两字换行，「+ 新章节」被 flex 压缩至 36×72 且溢出到 x≈288（超出 240px 栏宽），被右侧内容面板头部（「第 1 章」标题栏）完整盖住：`elementFromPoint` 命中内容头部 div 而非按钮；视觉上按钮不可见。
   - 复现范围：默认窗口 1264×761 与真实加宽后 1864×1001（Win32 MoveWindow）两种尺寸均复现，按钮 rect 完全不变，与窗口宽度无关。
   - 影响：用户经 UI 无法创建章节（新书写作流程断裂）；`button.click()`（JS）可触发同一 handler，说明仅布局/遮挡问题、逻辑正常。
   - 证据：`tmp/m13-bb-diag3-write.png`（挤压布局）、`tmp/m13-bb-diag6-wide.png`（加宽后依旧）、p1b/p1c 运行日志（真实点击 4 次无 api 调用）。
   - 备注：本次验收中建章降级为 DOM click() 触发（真实输入法键入不受影响）；书架页布局正常，问题仅限写作台。

2. **「首章完稿」里程碑日期口径与本地日期不一致（低危）**
   - 章节于本地 2026-09-11 00:03 首次保存（UTC 2026-09-10T16:03Z）：「首章完稿 达成于 2026-09-10」（UTC 口径），而「首次创作 达成于 2026-09-11」（快照本地日口径）。同一页面两个里程碑日期基准不同，UTC+8 零点后写作会显示差一天。

## 脚本问题（非应用缺陷）
- 弹窗/按钮真实点击偶发不注册（probe3、p1 首轮）→ 以「点击-验证-重试」缓解。
- DB 行无 `delta` 列（delta 为 API 层 last−base 计算），首轮断言误用字段。
- 统计页 label 与数值间为空行（`\n\n`），首轮正则漏配（证据已在页面文本转储中补齐）。
- 删除按钮 hover 显示在 CDP 下时灵时不灵；确认按钮文本「确认删除」首轮正则未覆盖。
- diag7 页面表达式正则转义错误、diag8 误覆盖 lib 的 ws.onmessage 导致脚本挂起（已终止该脚本，对应用无影响，渲染进程未阻塞）。
