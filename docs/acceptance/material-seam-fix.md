# 划词上下文衔接修复 — 验收材料

## 背景
用户反馈：划词润色/扩写/改写生成的文字有时与上下文冲突或衔接不好。commit 683262d 修复。

## 根因（探索代理确证）
1. contextTail 传编辑器全文（含选区+选区后文字）且 trimTail 锚定文档末尾 → 选区紧邻前文可能不在窗口；选区后文被错标为「前文结尾」诱导 AI 复述 → 替换后与文档保留的后文重复冲突；选区文字出现两次
2. 提示词无衔接纪律（无接前文末句/接后文首句/禁重复/片段形态保持/扩写长度目标）
3. selectionTarget 只有 {from,to,text}，AI 结构性不知道结尾接什么
4. aiTextToHtml 一律包 <p> 块，句中片段替换把原段拆成三段

## 修改内容
- aiWriting.ts：buildSelectionMessages 新签名 (ctx, sel:{text,before,after}, action, customInstruction?)；三段式提示词【选区前文】【待处理原文】【选区后文】+ 衔接纪律（开头接前文末句/结尾接后文首句/禁止重复前后文/片段保持片段/扩写 2~3 倍长度）
- ChapterEditor.vue：selectionTarget 快照时用 textBetween 截取选区前/后各 1500 字窗口（截断加…）；采纳区分形态——同段落内（resolve(from).sameParent(resolve(to))）行内纯文本替换（折叠换行）不拆段，跨段才走 aiTextToHtml 块替换
- 回归：续写/整章润色路径未动

## 开发自测声明（CDP 真实 Electron，tmp/seam-verify.mjs + tmp/seam-regression.mjs）
- 句中片段润色：3 段正文选第二段内片段 → 润色 33 字 → 采纳 → 段落数 3 不变（不拆段）、原片段已替换、前文/后文保留、输出不含后文句子；衔接自然（"井绳冰凉刺骨。→他仰起头…→远处传来鸡鸣"）
- 回归①续写：595 字正常落正文
- 回归②整章润色：块替换正常（多段落输出）
- 回归③跨段选区：走块替换路径正常
- typecheck 双 0

## 验收点
1. 句中片段划词润色/扩写/改写：采纳后段落结构不破坏（不拆段）、开头结尾与前后文自然衔接、不重复前后文句子
2. 扩写有合理长度（约为原文 2~3 倍）
3. 回归：续写/整章润色/跨段选区替换全部正常
4. typecheck 双 0

## 已知边界
- 输出与前文的重叠检测未做（提示词纪律约束，未做程序化检测）
- 行内替换时折叠换行（\n+→空），片段形态由提示词约束保障
