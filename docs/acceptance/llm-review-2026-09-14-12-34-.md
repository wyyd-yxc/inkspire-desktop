# LLM 审查（glm-5.1）

> 材料来源：material-M17-visual.md

## 结论

**有条件通过**：核心令牌体系、双主题架构与封面系统骨架已落地，但启动画面深色模式下存在可静态判定的严重视觉缺陷（Logo 隐形），且主题初始化链路在 `system` 模式下的解析逻辑存在高危风险。

## 发现的问题

### 1. [严重] 启动画面深色模式 Logo 隐形（对比度灾难）
- **位置**：`src/renderer/index.html`
- **现象**：`<svg>` 中 `stroke="#3a352e"` 与 `fill="#3a352e"` 硬编码了浅色模式的炭墨色，深色模式 CSS 媒体查询仅修改了背景与文字颜色，**未覆盖 SVG 内部颜色**。
- **后果**：深色底 `#171512` 与 墨色 `#3a352e` 对比度极低（约 1.32:1），深色模式启动时 Logo 完全融入背景不可见，严重违背品牌展示与无障碍要求。
- **修复建议**：在 `@media (prefers-color-scheme: dark)` 中增加对 `#boot-splash svg rect` 和 `#boot-splash svg path` 的 `stroke/fill` 覆盖，改为 `brand.ts` 中定义的暖白色 `#e3dbc9`，朱砂点改为 `#da8577`。

### 2. [中等] `system` 主题可能引发的首帧 FOUC/全量失效
- **位置**：`src/main/index.ts` → `src/preload/index.ts` → `useTheme.ts`
- **现象**：主进程直接将存储值（可能是 `"system"`）原样传入 `--inkspire-theme=system`，preload 原样暴露 `window.__inkspire_theme__ = "system"`。若 `applyThemeBeforeMount()` 未做 `window.matchMedia('(prefers-color-scheme: dark)')` 判定，直接执行 `document.documentElement.dataset.theme = "system"`，CSS 选择器 `[data-theme="dark"]` 将无法匹配。
- **后果**：选择「跟随系统」的用户，即使系统为深色，应用也只会呈现浅色或无样式状态。
- **修复建议**：主进程传入 `system` 时，应在渲染层 `applyThemeBeforeMount` 中增加解析逻辑：`const realTheme = arg === 'system' ? (matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light') : arg`。

### 3. [低] 组件焦点状态样式潜在冲突
- **位置**：`ApiProfileDialog.vue` 等多处输入框
- **现象**：输入框保留了 `focus:border-ink-primary`，同时全局 `theme.css` 注入了 `:focus-visible { box-shadow: var(--focus-ring) }`。
- **后果**：焦点激活时，边框颜色变为主色 + 外围双环阴影同时出现，视觉上可能显得粗重或焦点环被边框色吞噬，与设计令牌「焦点环」独立语义冲突。
- **修复建议**：统一移除组件级 `focus:border-*`，完全依赖全局 `box-shadow` 焦点环表现。

## 无法判定项

1. **`applyThemeBeforeMount` 的实际实现**：diff 中缺失 `useTheme.ts` 全文，无法判定其是否正确处理了 `system` 解析（如问题 2 所述），需运行验证或补充代码。
2. **九题材 SVG 底纹渲染完整性**：`coverArt.ts` 与 `BookCover.vue` diff 截断，无法判定 9 种 SVG pattern 定义是否存在路径错误或属性缺失。
3. **`@font-face` 声明合规性**：缺失 `theme.css` diff，无法判定 woff2 字体的 `font-weight`、`unicode-range` 及 CSP 白名单配置是否正确。
4. **ICO 产物尺寸完整性**：`build/icon.ico` 为二进制文件，静态无法验证是否真包含 7 尺寸 PNG 嵌入。
5. **`initTheme()` 在 `App.vue` onMounted 异步调用的副作用**：`void initTheme()` 在挂载后执行，若内部存在异步写入或 DOM 操作，是否会导致微小的主题闪烁，需运行高帧率录屏验证。
