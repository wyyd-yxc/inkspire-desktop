# 设计目标（Design Goals）

> 版本：v1.0 · 日期：2026-08-22 · 本文件回答「产品做什么、不做什么、做到什么程度算好」。

## 1. 一句话定位

复刻 inkspires.cn（墨灵小说）的全功能，做成 **Windows 桌面版 AI 网文创作工作台**：本地存储、开箱即用、AI 能力由用户自定义 API 提供。

## 2. 目标用户与使用场景

- 用户本人（编程小白 + 网文创作爱好者），单机使用，无多人协作需求。
- 场景：从一句灵感出发 → 建设定 → 规划章节 → AI 辅助写作 → 长篇连载不崩设定。

## 3. 产品范围

### 3.1 做（复刻自原站，按官方文档定义）

| 模块 | 核心能力 |
|---|---|
| 书斋 | 书籍列表、新建（书名/分类/简介/封面）、导入、删除 |
| 创世台 | 五步开局：定风（风格包）→定魂（Logline）→造世（世界观）→布局（大纲）→执笔；AI 冷启动 |
| 万物百科 | 人物/地点/势力/物品/规则词条 CRUD；AI 写作时自动参考注入 |
| 章节画布 | 单章场景节点编排；7 种场景生成模式；AI 按场景生成正文 |
| 剧情画布 | 跨章节事件节点+连线（因果/顺序），主线/支线/人物弧线 |
| 正文工作台 | 沉浸编辑器；幽灵续写；划词润色/扩写/改写；整章润色；自动保存 |
| 作品记忆 | 事实层：角色状态、剧情进展、开放伏笔；生成前注入防穿帮 |
| 墨灵助手 | 右下角浮球全局对话；@召唤百科词条；带选中上下文 |
| 灵感墙 | 便签（灵感/伏笔/片段/备忘/待办）；关联节点；拖入画布 |
| 作品风格/拆书 | 全书文笔调性约束；上传参考书拆解生成风格包 |
| Agent 体系 | 按功能场景划分的 23 个智能体，每个可绑定不同模型档案 |
| 创作统计 | 字数热力图、里程碑 |

### 3.2 不做（桌面版与原站形态差异，刻意决定）

- **不做**账号/注册/登录/积分/订阅——桌面单机免费无限用。
- **不做**云端同步与多人协作（后期若需要，另行立项）。
- **首期不做**图像生成（封面等）与联网搜索——架构预留，后期接。
- **不做**移动端/网页版。

## 4. 关键非功能目标（按优先级）

1. **可靠**：数据绝不丢（SQLite + 定时保存 + 安全线程），异常有提示不闪退。
2. **可交接**：任何模型按 docs/ 即可接手；文档与代码不一致视为 bug。
3. **可扩展**：AI Provider 抽象，新增协议不动上层；Agent 与模型解耦，可自定义。
4. **像原站**：UI 布局/配色/交互先按官方文档还原，用户后续提供截图校准。
5. **流畅**：编辑器打字零卡顿；AI 流式输出可中断；十万字级章节不卡。

## 5. 成功标准

- 最终在全新 Windows 机器上双击安装包 → 建书 → 创世 → AI 写完第一章，全程无报错。
- 每个里程碑有验收报告可查，git 历史清晰可回溯。

## 6. 约束与风险

- 用户为编程小白：所有面向用户的解释须通俗；升级/迁移脚本需自带说明。
- 原站 UI 细节以文档截图为基准推断，存在偏差风险 → 由用户截图校准闭环。
- API 质量取决于用户所选模型；应用需妥善处理超时/限流/格式错误并给出可读提示。
- 版权边界：仅借鉴功能与视觉风格，全部代码原创，不复制原站任何代码/素材。
