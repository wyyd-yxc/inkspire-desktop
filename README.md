# 墨笺 InkSpire

> AI 驱动的长篇小说创作工作台 —— Windows 桌面应用，本地数据 + 自定义 AI API

墨笺是一款面向网文/长篇小说作者的桌面创作工具：所有数据存在本地 SQLite，AI 能力由你自己的 API（任意 OpenAI 兼容协议）驱动，密钥不经过任何第三方服务器。

## 核心特性

**创作**
- 📚 **书斋** —— 书籍管理、封面系统（九大题材风格）
- ✍️ **正文工作台** —— 章节树 + TipTap 富文本编辑器 + 自动保存
- 🌅 **创世台** —— 五步生成世界观/人设/主线设定，一键接入正文
- 🧠 **AI 写作** —— 续写、划词指令、整章润色，流式输出
- 💡 **灵感墙** —— 五类便签，划词存灵感，一键入画布

**规划**
- 🔗 **章节画布** —— 节点式章节结构规划与连线
- 🕸️ **剧情画布** —— 事件节点 + 四类关系连线，AI 辅助剧情推演（三模式）
- 📖 **万物百科** —— 角色/地点/物品等设定条目，正文划词提取

**风格与记忆**
- 🎨 **作品风格** —— 风格包管理、绑定优先级注入、AI 生成封面
- 📕 **拆书** —— 导入 txt 参考文本，AI 拆解为可复用的风格 digest（参考文本不落库、不持久）
- 🗂️ **作品记忆** —— 跨模块上下文，自动注入 AI 请求

**辅助**
- 🤖 **墨灵助手** —— 书内全局浮球，聊天 + @召唤任意模块数据
- 📊 **创作统计** —— 字数快照、目标进度、趋势折线、热力图、里程碑
- ⚙️ **Agent 模型偏好** —— 8 个功能槽位可绑定不同 AI 档案（如续写用 A 模型、拆书用 B 模型）

**视觉**
- 🖌️ **纸墨 2.0 设计** —— 双主题（纸墨浅色 / 深夜书房深色）、思源宋体本地子集、朱砂印 Logo

## 技术栈

| 层 | 技术 |
|---|---|
| 桌面框架 | Electron 43 + electron-vite |
| 前端 | Vue 3 · Pinia · Vue Router · Tailwind CSS 4 |
| 编辑器 | TipTap 3 |
| 画布 | Vue Flow |
| 存储 | better-sqlite3（本地数据库，migration 版本化管理） |
| 语言 | TypeScript |

## 快速开始

环境要求：Node.js ≥ 20，Windows（打包目标为 NSIS 安装包）

```bash
npm install
npm run dev      # 开发模式
npm run dist     # 打包 Windows 安装包（输出到 release/）
```

首次使用：启动后在「设置中心」填入你的 AI API 信息（OpenAI 兼容的 Base URL + API Key），即可使用全部 AI 功能。

## 数据与隐私

- 创作数据全部存储在本地 SQLite 数据库，无云端同步、无遥测
- AI 请求直接从本机发往你配置的 API 端点，API Key 仅保存在本地

## 目录结构

```
src/
  main/           # Electron 主进程：数据库、AI 通道、窗口管理
  preload/        # 预加载桥
  renderer/       # Vue 3 渲染进程（页面、组件、状态）
docs/
  HANDOVER.md     # 项目交接文档（开发过程总入口）
  plan/           # roadmap 与任务定义
  acceptance/     # 各里程碑验收报告
  design/         # 架构与视觉设计规范
  worklog/        # 开发日志
```

## 开发过程

本项目采用「AI 结对 + 双轨验收」的开发方式：每个里程碑经过静态代码审查与真实环境黑盒测试双轨验收后才打 tag 收尾。完整的 23 个里程碑（M0–M17）、215+ 提交记录与全部验收报告都在仓库中，`docs/HANDOVER.md` 是总入口——如果你对「如何用 AI 驱动完成一个完整桌面应用」感兴趣，这部分文档可能比代码本身更有参考价值。
